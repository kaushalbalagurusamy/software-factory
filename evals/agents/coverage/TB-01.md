- The `graph` position in the check order (behaviour 2): TB-01 lists `graph` in the order but puts graph validation out of scope, so what TB-01 rejects under `graph` is undefined (ambiguities A-02).
- Defaults of optional fields with no default shown in the contract (held_out, frozen_tests, baseline_update, agents, mcp_servers, graph, deploy, checks, pattern lists): empty versus null is not specified (A-03).
- `..` as a substring inside a name (for example `a..b`) (A-05).
