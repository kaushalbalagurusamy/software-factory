- select when only the original start stages are removed (for example the base fixture's `small` subset): the two readings of "removes every start or end stage" disagree (A-25).
- Reachability ("every stage has a path from a start stage") is implied by acyclicity of `edges`, so no separate failing input exists.
- Tie-breaking where Kahn smallest-id-first and level-by-level orders disagree (A-27).
- Whether loops between kept stages survive select; subsets naming unknown roles (A-29).
