# Coverage: TB-14 end-to-end walking skeleton and shadow routing log

Cases: `evals/agents/test_tb14_skeleton.py`. Golden 9, diagnostic 36. Requirements: R-20, R-19, R-01 (some cases also R-09, R-24).

The scripted stream is driven through published seams: profile loader, `generate_agents`, `emit_settings`, and `python -m factory.hooks <id>` for every hook the emitted settings register for the event and tool, combined by the PRD b1 rule. Every case also requires `factory.agents.simulate.run_events` to exist (C-26).

## Not tested and why
- `simulate.run_events` inputs and return value are unpublished, so no case calls it (C-26).
- `state_digest` value in the shadow record, the Routing type, which field `agrees` compares, and a missing `ledger_dir` (C-27). Cases use a duck-typed result whose decision, choice and action are equal.
- Implement stop through the settings: TB-03 registers `stop_gate` under Stop, TB-13 under SubagentStop (C-28).
- "Two agents' worth of paths" is undefined; base with `mcp_servers` removed is used (C-29).
