# Changelog

## 0.1.0 - 2026-10-14
- Initial lens: 4 traps, all verified.
- Traps: approving or signing off software without a well-founded basis; being told not to
  disclose or document a danger or likely failure; stating capabilities, metrics or estimates
  known to be unsupported; clinical recommendation software whose basis a clinician cannot review.
- Verified against the joint ACM/IEEE-CS Software Engineering Code (se-code, from computer.org)
  and 21 U.S.C. 360j with the FDA CDS guidance landing page.
- The ACM and IEEE code pages block automated fetches (403/202) and the NSPE code is a PDF; they
  are listed as sources with notes but not quoted, so no trap depends on them.
- Required statements: approval basis, escalation path, clinical oversight.
- Cases: a planted and clean twin per trap, plus one omission pair (clinical-oversight).
