# Glossary

Plain words for the technical terms used in these pages. Copy this file to
`docs/eli12/GLOSSARY.md`. Add one line per term, the term first, then a colon, then a meaning a
12-year-old can follow. `eli12.py check` complains when a term from the jargon list is used in a
page but has no line here.

- webhook: a web address that another program calls to tell us "something just happened".
- payload: the actual message inside a package of data, without the labels around it.
